# Model access decisions

## Current

- Model access is explicit authorization, not automatic routing or Provider installation.
- One effective policy snapshot is the source for runtime authorization, Agent guidance, and settings projections.

## Superseded

- Earlier switch, assignment, queue-revalidation, and global Thinking-default behavior is retained only as historical evidence. See [refactoring-history-audit.md](../../../../docs/refactoring-history-audit.md) and the accepted model-access ADRs until migration documents absorb them.

## Implementation-only

- Menu row IDs, current manager methods, and ConfigStore mutation names are not policy terms.
